# PKO2 - atualizações do cliente

Este repositório só guarda as **Releases** usadas pelo PKO Launcher.

## Como jogar
1. Baixe o `PKOLauncher.exe` da [release mais recente](https://github.com/FelipeSantanaIV/pko2-patches/releases/latest).
2. Coloque-o numa pasta vazia (ex.: `C:\Jogos\PKO2`, não em Arquivos de Programas) e abra.
   Na primeira vez ele baixa o jogo inteiro; depois, só as atualizações.
3. Siga as instruções do launcher para entrar na rede ZeroTier do servidor.

Não apague releases antigas: as versões novas reaproveitam pacotes delas.
